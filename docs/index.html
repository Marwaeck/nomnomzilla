Nom nom! Euer Familien­rezeptbuch auf dem eigenen Server.

NomNomZilla läuft als kleiner Docker-Container auf deinem Unraid-Server oder in Docker Desktop. Im Heimnetz ist es auf jedem Handy, Tablet und Laptop erreichbar, und jedes Rezept wird auf Knopfdruck zur hübschen DIN-A4-Rezeptkarte.

Was NomNomZilla kann

Alles, was ein Familien-Rezeptbuch braucht, und nichts, was nervt.

🔍

Finden statt suchen

Suche nach Rezept, Zutat oder Stichwort. Gruppiere nach Kategorie, Küche, Ernährung, Zeit, Schwierigkeit, Saison oder Hauptzutat.

🖨️

Rezeptkarten exportieren

Jedes Rezept als DIN-A4-Karte im PDF-, PNG- oder HTML-Format. Mehrere Karten landen auf Wunsch in einem PDF.

Vier kurze Fragen, dann ein Vorschlag aus euren Rezepten. Bevorzugt das, was ihr länger nicht gekocht habt.

🔄

Live auf allen Geräten

📄

Eigene Karten wieder einlesen

Exportierte Rezeptkarten-PDFs lassen sich wieder hochladen, auch viele auf einmal. Ganz ohne Internet.

Installieren

Such dir aus, wo Zilla wohnen soll. Das Image {{ site.image }} läuft auf Intel/AMD und ARM, also auch auf Apple-Silicon-Macs und dem Raspberry Pi.

Unraid

  1. Im Unraid-Terminal das Template einmal hinterlegen: 
    wget -O /boot/config/plugins/dockerMan/templates-user/my-NomNomZilla.xml \
  https://raw.githubusercontent.com/Marwaeck/nomnomzilla/main/unraid/nomnomzilla.xml
  2. Docker → Container hinzufügen → bei „Vorlage“ NomNomZilla wählen.
  3. Optional Passwort und Anthropic-API-Schlüssel eintragen, dann Anwenden.
  4. Fertig: http://<unraid-ip>:6767 im Browser öffnen.

Updates kommen automatisch: Bei jeder neuen Version zeigt Unraid „Update verfügbar“, ein Klick genügt. Die Rezepte liegen in /mnt/user/appdata/nomnomzilla und bleiben erhalten.

Docker Desktop (Windows, Mac, Linux)

  1. Docker Desktop installieren und starten.
  2. Ein Terminal öffnen (Windows: PowerShell, Mac: Terminal) und diesen einen Befehl einfügen: 
    docker run -d --name nomnomzilla --restart unless-stopped -p 6767:8080 -v nomnomzilla-data:/data ghcr.io/marwaeck/nomnomzilla:latest
  3. http://localhost:6767 öffnen. Im Heimnetz erreichen die anderen Geräte NomNomZilla unter der IP deines Rechners, zum Beispiel http://192.168.1.20:6767.

Die Rezepte liegen im Docker-Volume nomnomzilla-data. In Docker Desktop findest du es unter Volumes. Zum Aktualisieren den Container in Docker Desktop löschen (das Volume bleibt), docker pull ghcr.io/marwaeck/nomnomzilla:latest ausführen und den Befehl oben erneut starten. Bequemer geht das mit Compose.

Docker Compose

  1. Einen Ordner anlegen und docker-compose.yml sowie .env.example hineinladen.
  2. .env.example in .env umbenennen und bei Bedarf Passwort, API-Schlüssel oder Port eintragen.
  3. Im Ordner starten: 
    docker compose up -d
  4. http://localhost:6767 öffnen.

Aktualisieren: docker compose pull && docker compose up -d. Die Rezepte bleiben im Volume nomnomzilla-data.

Einstellungen

Alles optional. Ohne Einstellungen läuft NomNomZilla sofort.

VariableWofür
APP_PASSWORDPasswortschutz. Der Browser fragt einmal nach Benutzername (beliebig) und Passwort.
ANTHROPIC_API_KEYSchaltet den Claude-Import für fremde PDFs und Text frei.
ANTHROPIC_MODELModell für den Import, Standard claude-sonnet-5-5.
PUID / PGIDBesitzer der Dateien in /data, Standard 99/100 (Unraid).

Import mit Claude scharfschalten

Rezept aus der Zeitschrift abfotografiert, PDF von der Freundin bekommen oder Text aus einem Blog kopiert? Mit einem Anthropic-API-Schlüssel liest Claude das ein und füllt alle Felder aus. Ohne Schlüssel funktioniert alles andere ganz normal.

  1. Unter console.anthropic.com einen API-Schlüssel anlegen und etwas Guthaben aufladen.
  2. Den Schlüssel als ANTHROPIC_API_KEY eintragen (Unraid-Template, .env oder -e beim docker run) und den Container neu starten.
  3. Unter Importieren kannst du jetzt auch fremde PDFs und Text einlesen.

Kosten: etwa ein Cent pro Rezept, gescannte Seiten etwas mehr. Der Schlüssel bleibt auf dem Server, der Browser sieht ihn nie.

Gut zu wissen

Braucht NomNomZilla Internet?

Nein. Suche, Bearbeiten, Kartenexport und PDF-Upload laufen komplett im Container und im Browser. Es werden keine CDNs oder Schriften aus dem Internet geladen. Nur der optionale Claude-Import spricht mit der Anthropic-API.

Wo liegen meine Rezepte, und wie sichere ich sie?

In einer einzigen Datei recipes.json im Datenordner (Unraid: /mnt/user/appdata/nomnomzilla, Docker Desktop: Volume nomnomzilla-data). Zusätzlich lädt der Knopf Sicherung herunterladen in der App die aktuelle Datei herunter.

Kann ich von unterwegs zugreifen?

Am einfachsten über ein VPN wie WireGuard oder Tailscale. Wenn du NomNomZilla über einen Reverse Proxy ins Internet stellst, setz unbedingt APP_PASSWORD und nutze HTTPS.

Der Container startet nicht.

Meist ist der Port schon belegt („port is already allocated“). Dann einen anderen Host-Port nehmen, zum Beispiel -p 6780:8080. Ports 6665 bis 6669 meiden, die blockieren Browser. Im Log steht bei einem normalen Start „NomNomZilla läuft auf Port 8080“.
